จัดกลุ่มทั้งไฟล์

ใช้ไฟล์ .dbf รูปแบบเดียวกับที่เคยส่งให้โปรแกรม TGrp6305 ได้ไฟล์เดิมกลับไป พร้อมผลในคอลัมน์ DRG, MDC, ERR, WARN, RW, ADJRW, WTLOS, OT และ ACTLOS คอลัมน์อื่นและข้อความภาษาไทยยังอยู่ครบ

เซิร์ฟเวอร์ประมวลผลไฟล์ในหน่วยความจำเท่านั้น ไม่บันทึกลงดิสก์และไม่เขียนลง log

ตรรกะเขียนจากหนังสือ Thai DRG Version 6.3.3 ของ สรท. และใช้ตารางรุ่น 6.3.4 โปรแกรมนี้ไม่ได้จัดทำหรือรับรองโดย สรท. ควรตรวจผลกับโปรแกรมทางการก่อนใช้เบิกจ่าย
